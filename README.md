# Monster Crypto Devnet metadata

Public, non-secret metadata and imagery for the Monster Crypto Devnet Metaplex Core collection.

- `collection.json` is the collection metadata document.
- `collection-cover-v1.png` is original collection artwork generated for this Devnet-only asset.

No private keys, credentials, wallet signatures, player data, or production metadata belong here.
The collection metadata URI must be served through GitHub Pages so it has an HTTPS
`application/json` content type; `raw.githubusercontent.com` intentionally is not used for JSON.
